# Cognito Blox

Interactive learning blocks for **Articulate Rise 360** Custom Code. Pick a block, fill in a form, copy one HTML file, paste into Rise.

**Live app:** [cognitoblox.netlify.app](https://cognitoblox.netlify.app/)  
**Demo in Rise 360:** [See it in a published course](https://akshayubc.github.io/cognitoblox/index.html)

This GitHub repository is documentation only. It does not include the application source code. Use the live app to build and copy blocks.

---

## How to use (Rise 360)

1. Open [cognitoblox.netlify.app](https://cognitoblox.netlify.app/) and click a component.
2. Fill in the form (text, colors, images). The preview updates as you type.
3. Click **Copy** next to the **live preview window** (single HTML file with inline CSS and JavaScript).
4. In Rise 360, add a block: **+ → `</> Code` → Add Code**.
5. Paste the code, click **Done**, preview, then publish.

That is the full workflow. No install needed for authors.

## Copy options

On each component page you can:

- **Rise 360 Compatible** — one HTML file (use this in Rise)
- **Download** — save the same file locally
- **HTML / CSS / JavaScript** — separate snippets if you use another platform

Generated code uses plain HTML, CSS, and JavaScript only. No external libraries in the output.

## Troubleshooting

**Block does not show in Rise**
- Confirm you copied **Rise 360 Compatible**, not HTML/CSS/JS separately.
- Paste into a Custom Code block and click **Done**.

**Images missing**
- URL must be public and start with `https://`.
- Try uploading the image in the form instead.

**Looks different in Rise**
- Rise adds its own container styles. Use Rise preview as the final check.
