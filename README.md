# CognitoBlox

**Professional interactive learning elements for Rise 360 and web development**

CognitoBlox provides accessible, customizable HTML/CSS/JavaScript components that integrate seamlessly with Articulate Rise 360's Custom Code blocks and other web platforms.

---

## 🚀 How to Use CognitoBlox

### Step 1: Select a Component

Visit [CognitoBlox](http://localhost:3000) and browse the available learning components:

- **Reflective Journal** - Text area for personal reflections with local storage
- **Scenario Judgement Card** - Decision-making scenarios with feedback
- **Flashcards** - Flip cards for terms and definitions
- **Before/After Image Slider** - Draggable image comparison slider
- **Stepwise Process Flow** - Interactive step-by-step process visualization

Click on any component card to open its generator page.

---

### Step 2: Fill Out the Form

On the component page, you'll see a form on the left side with customizable fields:

1. **Required Fields** - Fill in essential information like titles, text content, and options
2. **Optional Fields** - Add images, customize colors, or add extra content as needed
3. **Live Preview** - Watch the component update in real-time as you fill out the form

**Example for Flashcards:**
- Enter question/term on the front
- Enter answer/definition on the back
- Optionally add images
- Choose Text overlay colors

---

### Step 3: Copy the Code

Once you're happy with your component, you have several export options:

#### **For Rise 360 (Recommended):**
1. Click the **"Copy"** button next to "Rise 360 Compatible"
2. This copies a single HTML file with all styles and scripts inline
3. Ready to paste directly into Rise 360!

#### **For Web Development:**
- Copy individual **HTML**, **CSS**, or **JavaScript** files
- Or download the single file using the **"Download"** button

---

### Step 4: Paste into Rise 360

#### In Articulate Rise 360:

1. **Add a Custom Code Block**
   - In your Rise 360 course, click the **"+"** button to add content
   - Select **"</> Code"** from the block library 
   - Click on the **"Add Code"** option

2. **Paste Your Code**
   - After the code block appears, click **"Add Code"** in the Custom Code block
   - Click in the code editor area
   - Press **Cmd+V** (Mac) or **Ctrl+V** (Windows) to paste your code

3. **Preview & Publish**
   - Click **"Done"** to save the code
   - Use Rise 360's preview feature to test the component
   - Publish your course when ready!

## 🛠️ Tips & Best Practices

### Images
- Use **web-optimized images** (JPG, PNG, WebP)
- Recommended size: **under 500KB** per image for fast loading
- Use image URLs (hosted online) or base64-encoded data URLs

### Text Content
- Keep **titles concise** (3-5 words work best)
- Write **clear, actionable descriptions**
- Test with different text lengths to ensure good display

### Colors
- Use the **color picker** for consistent branding
- Ensure **sufficient contrast** for readability (test with WCAG tools)
- Consider colorblind users when choosing color schemes

### Testing
- **Always preview** in Rise 360 before publishing
- Test on **multiple devices** (desktop, tablet, mobile)
- Check **keyboard navigation** and screen reader compatibility

## 🆘 Troubleshooting

### Component Not Displaying in Rise 360
- Ensure you copied the **"Rise 360 Compatible"** version (single HTML file)
- Check that you pasted into a **Custom Code block** (not a text block)
- Try clicking "Done" and reopening the Custom Code block

### Styles Look Different
- The single HTML file includes all necessary styles inline
- Rise 360 may apply its own container styles - this is normal
- Use the preview feature to see the final result

### Images Not Showing
- Verify image URLs are publicly accessible
- Check that URLs start with `https://` (not `http://`)
- Consider using base64-encoded images for better reliability

### Form Data Lost
- Form data is saved in **browser localStorage**
- Clearing browser data will reset forms
- Use the **Copy** button to save code before clearing browser data
